HTMLGO-M

An offline-first Web Application Runner, Local Workspace Engine, and AI-assisted HTML/WebGL sandbox (com.absolutemango.htmlgom) built natively for Android and Wear OS.

Status & End-of-Life Notice

This page documents the final archived release (v2.0R - EOL / Build 4) of HTMLGO-M. Active feature development has concluded, and the complete multi-module codebase is published under the GNU General Public License v3.0 (GPL-3.0) as a permanent community archive.

Key Features

Run standalone HTML files, ZIP web bundles, WebGL shaders, and Markdown/LaTeX documents with zero external servers.

⚡

Dual Rendering Engines

Switch seamlessly between hardware-accelerated system WebView for instant startup and embedded Mozilla GeckoView for desktop-grade WebGL & HTML5.

✨

AI Forge Studio

Generate and live-preview web apps on-device with one-tap Play execution, a hardware-encrypted BYOK Vault, backup API failover, and custom Mr. Forger prompts.

⌚

Wear OS Companion

Pair with HTMLGO-W to send HTML apps and .zip bundles directly to your smartwatch over the Wear OS Data Layer with rotating-bezel navigation.

🛠️

Workspace & Sora Editor

Manage local /workspace projects with built-in Sora Editor syntax highlighting, an Emergency Browser, and native Rust-powered ZIP archive tools.

🎨

Liquid Glass & Monet

Material 3 Expressive theming computed live from your wallpaper across 9 color schemes, powered by AGSL refractive shaders and Haze blur layers.

🖤

AMOLED & Solid Mode

Pure #000000 Extra Black mode for OLED panels, plus a toggleable Solid Gradient Mode to disable blur overlays for maximum battery efficiency.

Build from Source

Requires JDK 17+, Android SDK, and the Rust toolchain for app/htmlgom/rust-core.

bash Gradle Multi-Module 
# 1. Clone the repository
git clone https://github.com/Absolute-Mango-co/HTMLGO-M.git
cd HTMLGO-M

# 2. Build the Android mobile APK
./gradlew :app:htmlgom:assembleRelease

# 3. Build the Wear OS companion APK
./gradlew :htmlgow:assembleRelease
